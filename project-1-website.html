Website Reflection

My HTML and CSS Website Development Process

The Process

When I first started creating this website, I learnt the different components of HTML and CSS. HTML provides the structure of a website, while CSS controls its appearance. As I gained experience, I learnt how to use elements such as headings, paragraphs, divisions and links. I used these skills to connect different pages, including my GitHub profile and other projects. Over time, I developed my website by adding features such as a gradient background, images and clickable navigation links. This project helped me understand how websites are designed and built.

Key Decisions

One important decision was planning the overall appearance of my website before adding more complex features. This helped me create a design that was organised and easy to navigate.

I chose a gradient background because it makes the website more visually interesting and gives it a distinctive style.

I also included a profile image and a link to my GitHub profile. These features help personalise my website and allow visitors to explore my other work.

I focused on responsive design so the website could adjust to different screen sizes. This makes it easier to use on phones, tablets and computers.

Challenges

One of the main challenges I faced was positioning text, images and boxes correctly. I had to experiment with CSS properties to align elements and create a balanced layout.

Another challenge was creating the gradient background. I learnt how to use the linear-gradient function and experimented with different colours and directions until I achieved the appearance I wanted.

I also had many different ideas for the structure of my website, which made it difficult to choose a final design. After considering my teacher's advice, I decided to use a simple but detailed layout that I could realistically create and maintain.

Skills and Technologies Used

I used several technologies and skills throughout this project, including HTML, CSS, responsive design, Visual Studio Code, Git and GitHub.

HTML: I used HTML to organise the content and structure of my website using headings, paragraphs, links and other elements.

CSS: I used CSS to improve the appearance of the website through colours, gradients, spacing, borders, fonts and layouts.

Responsive design: I used responsive design techniques to help the website display clearly on different devices and screen sizes.

Visual Studio Code: I used Visual Studio Code to write and edit the HTML and CSS files for my website.

Git and GitHub: I used Git and GitHub to save changes, track my progress and publish my work so others could view it.
