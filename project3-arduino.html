Project Reflection

Project Overview

During Term 3, I created an Information Display, showing a live updating time, date, weather and a randomly selected quote. This was displayed on an Arduino Uno, a little screen that had to be connected to my laptop which processed the code I typed.

What Went Well

One thing that went well was getting the Arduino and screen to successfully display the information I wanted, which in this case was the time, date, weather and quote. I was able to use Python script to send information to the Arduino through a USB serial connection. I also managed to change the layout, text size and positioning to my liking. This made the final display look cleaner and more organised, using a white background with navy text.

Challenges and Problem Solving

There were also some difficult parts of the project. One main problem was getting the correct time to display. At one point during this task, the screen didn’t update the time, even though I followed the instructions set. I had to troubleshoot the Arduino and Python programs to find out what was causing the problem. This taught me to make sure old programs are stopped before testing new code.

Design and Technical Challenges

Another challenge was making everything fit properly on the screen. I had to adjust the text sizes and positions several time so the time, date, weather and quote were all visible. I also learned that some fonts do not support certain characters, which affected the Korean quotes I wanted to use.

Skills and Final Evaluation

Throughout this project, I learned how Python and Arduino can communicate with each other and how to control physical hardware. I also improved my debugging and problem solving skills by testing different solutions when something didn't work. Overall I am proud of my project because I was able to create a functioning Information Display and be able to have a broader understanding about how software and hardware work together.
